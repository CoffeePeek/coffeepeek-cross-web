# Импорт по ссылке

Расширение Manifest V3 для Chrome и Edge. Внешние страницы читаются в браузере; API CoffeePeek принимает только подтверждённые поля.

## Установка

1. В админке нажмите **По ссылке** → **Скачать**, распакуйте архив.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`), включите режим разработчика, нажмите **Загрузить распакованное расширение** и выберите распакованную папку.
3. На вкладке админки откройте значок расширения и нажмите **Подключить эту админку**. Разрешите доступ к этому домену.

Для обновления до **1.1.0** замените файлы распакованной папки новым архивом, нажмите **Обновить** у расширения и перезагрузите админку. Старое расширение не поддерживает поиск меню и загрузку фотографий.

## Использование

Вставьте ссылку на организацию Яндекса или профиль Instagram, нажмите **Получить данные**. Расширение откроет источник, прочитает доступные поля и вернёт предпросмотр в админку. Если источник требует вход или проверку, откройте его обычным образом в этом браузере и повторите импорт.

В текущую карточку можно сохранить телефон, сайт, Instagram и расписание. Заполненные поля по умолчанию не выбраны. Название, адрес, координаты и описание доступны для просмотра. Для новой кофейни обязательны название, адрес и координаты; недостающие данные можно заполнить в предпросмотре. Описание не сохраняется: текущий API кандидата не содержит этого поля.

Расширение следует по ссылкам на меню и галерею **той же организации** и читает Instagram из её контактов. Галерея прокручивается для загрузки фотографий (до 60). В предпросмотре можно открыть фото полностью и выбрать до четырёх для загрузки и существующего распознавания меню. Текстовые позиции сопоставляются со справочником напитков; остальные позиции доступны для просмотра. Для каждого напитка выбирается один объём. Цены доставки отмечены отдельно, диапазоны цен не превращаются в точную цену, граммы не используются как миллилитры. Существующие строки меню сохраняются при переносе напитков.

Теги выбираются по явным подтверждениям в особенностях организации, биографии Instagram и названиях напитков. Предлагаются только известные теги из активного справочника, каждый с источником и цитатой. Wi-Fi, продажа зерна и десерты сами по себе не дают тегов «Ноутбук», «Обжарка» или «Кондитерская». Выбор можно изменить перед сохранением.

Меню сохраняется через существующие `/menu`, `/menu/photos` и `/menu/parse`. Теги передаются в `/decide` при публикации; до этого найденные материалы и выбор тегов сохраняются в браузере. Для новой кофейни материалы восстанавливаются по `externalId` после добавления в очередь — откройте её карточку и **По ссылке**, чтобы перенести меню. Этот черновик не синхронизируется между браузерами. Сайты, PDF и Instagram Highlights показываются ссылками; их содержимое автоматически не распознаётся. Проверки входа и CAPTCHA не обходятся.

Создание использует существующий `POST /api/admin/import/file` как транспорт сохранения одного объекта. Загрузка JSON-файлов в интерфейс не возвращается. Этот endpoint может дополнить уже существующего кандидата при совпадении; результат сервера показывается как добавление, дополнение или отсутствие изменений. Сохранение контактов использует `PATCH /api/admin/import/candidates/{id}` с проверкой полей в ответе. Кофейня не публикуется автоматически.

Instagram извлекается из JSON профиля, JSON-LD и доступных элементов шапки. Яндекс — из JSON-LD, данных организации и элементов карточки. Центр карты из URL не используется как координаты кофейни. Разметка источников может меняться; отсутствующие поля не выдумываются. Данные сохраняются только после подтверждения.

## Сборка и проверки

```sh
npm ci
npm run extension:build
npm run typecheck
npm test
npm run build
```

Готовая папка: `browser-extension/dist`. Архив: `public/link-import-extension.zip`. Архив автоматически пересобирается перед `dev` и `build` и включается в Vite `dist`.

Сквозная проверка использует отдельный профиль Chromium, настоящее расширение, тестовую разметку обеих платформ и перехваченный API. Реальные данные CoffeePeek не изменяются.

```sh
npx playwright install chromium --no-shell
npm run dev
# В другом терминале:
npm run test:link-import
```

Можно указать `LINK_IMPORT_TEST_ORIGIN`, `LINK_IMPORT_CHROMIUM` (путь к Chromium) и `LINK_IMPORT_SCREENSHOTS` (папка скриншотов). Обычный Google Chrome не поддерживает автоматическую загрузку расширений через командную строку; для теста нужен Chromium / Chrome for Testing.

Для ручной проверки меню и тегов откройте `/tests/browser/link-import-enrichment.html` на Vite dev-сервере. Это настоящий интерфейс импорта с тестовыми API и сообщениями расширения; реальные данные не меняются. Проверяйте выбор объёма, сохранение существующих напитков, снятие тегов, публикацию, восстановление черновика после перезагрузки, игнорирование меню сервером и повтор после сбоя распознавания. Страница не входит в production-сборку.

## Доступ расширения

Постоянные разрешения ограничены доменами Яндекса, Instagram и их CDN фотографий. Загрузка изображения допускает только HTTPS на `avatars.mds.yandex.net/get-altay/…` и `*.cdninstagram.com`, без cookies и редиректов, до 8 МБ. Доступ к домену админки выдаётся через popup. Сообщения проверяют точный origin и верхний frame, URL источника, идентификатор организации/профиля и идентификатор запроса. Отмена закрывает созданные вкладки; поздний ответ не применяет данные. Заблокированные источники остаются открытыми для обычного входа пользователя. Расширение не читает токены CoffeePeek, cookies, историю браузера и не отправляет данные сторонним прокси.

Документация платформы: [Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts), [Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/messaging), [Playwright extensions](https://playwright.dev/docs/chrome-extensions).
