# Импорт меню и тегов — проверка 5 октября 2026

Реализовано в админке и расширении 1.1.0, без новых backend endpoints. Источники обходятся в браузере: своя карточка Яндекса → меню и галерея → связанный Instagram. Теги требуют явного подтверждения и совпадения с активным справочником.

## Живые источники

Через встроенный браузер прочитана текущая разметка, затем тот же TypeScript-парсер запущен на сохранённых DOM-фрагментах:

- [Don Coffe’On](https://yandex.by/maps/org/don_coffe_on/1148465931/menu/): 28 позиций, 28 цен BYN, 28 весов; все помечены как доставка. Это еда, поэтому она доступна для просмотра, а не переносится в справочник кофейных напитков.
- [Coffelion, Instagram](https://www.instagram.com/coffelion_minsk/): подтверждение `pet_friendly` из биографии и ссылка «Ассортимент». Содержимое закрытых Highlights не заявляется как прочитанное.
- [Coffelion, галерея](https://yandex.by/maps/org/coffelion/41070949812/gallery/): в начальном DOM загружены шесть фото. Расширение дополнительно прокручивает галерею, накапливая до 60 уникальных доступных фотографий. Фото выбирает пользователь; автоматической классификации изображений как меню нет.

## Проверка интерфейса

`tests/browser/link-import-enrichment.html` использует настоящий `ImportQueuePage` и диалог с тестовыми API и сообщениями расширения. Реальные данные CoffeePeek не изменялись.

Проверено: один объём на напиток, отметка доставки, перенос цены и объёма с сохранением существующего эспрессо, сохранение старого телефона, снятие предложенного тега, передача выбранного тега в публикацию, восстановление черновика после перезагрузки. Выбранное фото проходит загрузку, прикрепление и запуск распознавания. После ошибки распознавания повторяется только запуск; фото не загружается повторно. Игнорирование меню сервером показывает ошибку вместо успеха. На ширине 390 px диалог не имеет горизонтального переполнения.

Полный запуск установленного расширения в Chrome на живых сайтах не выполнялся. Worker проверен автоматическими тестами с имитацией Chrome API; интерфейс — в браузере с тестовыми ответами.

В изолированной копии подготовленного коммита `npm test`: 5 наборов, 47 тестов прошли. `npm run build`: проверка TypeScript, сборка расширения и production-сборка прошли. `git diff --check` прошёл. Проверен собранный ZIP: manifest 1.1.0, обход меню/галереи и загрузка изображений присутствуют.

## Ограничения

API хранит кофейные напитки. Позиции еды показываются для проверки, но не записываются как кофе. Сайты, PDF и Highlights доступны ссылками. Черновики найденных материалов и тегов локальны для браузера; теги отправляются серверу при публикации. Распознавание фото использует уже существующий backend механизм.
